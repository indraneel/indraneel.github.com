SharedStreets Road Closure Tool

visit the site | github

2018-2019

Technologies: React, Redux, Mapbox

I joined SharedStreets as the first employee. A few projects were spun up simultaneously to try to find a use for the SharedStreets linear referencing system.

I designed and built a web app myself with React/Redux using Mapbox to manage road closures. I worked with PANYNJ's data partnerships team to test an integration within their Agency Operations Center. The app used the SharedStreets referencing system to make the data easily translatable between various government and commercial base maps, to try and prevent vendor lock-in.

I wrote features based on PANYNJ feedback, such as scheduled closures, and code to munge data into the Waze CIFS format.

I gave talks about this project at:

  • State of the Map US 2019
  • Transit Techies meetup
